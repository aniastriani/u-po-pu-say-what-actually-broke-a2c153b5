## What it does

`main.py` (pure Python standard library, no dependencies) writes one brutally
honest, funny error line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The line is 137
characters, deterministic, and always the same bytes on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
cat /output/entry.txt
```

## Entry

> The server didn't crash, it just quietly stopped answering, like a coworker who saw your message and decided to pretend it never arrived.
